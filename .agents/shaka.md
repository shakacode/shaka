# Shaka configuration

Repository settings live in [shaka/config.yml](shaka/config.yml).
Run setup, tests, and validation through [shaka/bin/](shaka/bin/).
Public-comment trust is configured in [shaka/trusted-github-actors.yml](shaka/trusted-github-actors.yml).

See [the settings reference](../docs/settings.md) for supported choices.
Policy comes from the trusted default branch; proposed settings do not govern their own PR.
