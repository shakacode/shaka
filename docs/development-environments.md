# Development environments

Shaka runs inside your coding agent. That environment supplies the model,
permissions, and tools; Shaka guides the work through a reviewed pull request.

| Environment | Start a task | Pilot status |
| --- | --- | --- |
| Codex | `$shaka` | Delivery and startup trials recorded |
| Claude Code | `/shaka` | Complete consumer delivery recorded |
| Cursor | `/shaka` | Startup and usage capture tested; full delivery unverified |
| OpenCode | `/shaka` | Launcher and usage reader implemented; full delivery unverified |
| Pi | Load the installed Shaka skill | Usage-reader delivery trial; broader use unverified |

Use the [installation prompt](getting-started.md) in your chosen environment.
The [installation reference](agents/installation.md) has directory paths,
terminal commands, and usage-hook setup. The [validation record](project/host-validation.md)
lists tested versions and trial limits.
