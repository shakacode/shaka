# Repository catalog

If several projects use Shaka, compare their review and merge choices before
standardizing them:

```text
Refresh the Shaka catalog for my repositories. Compare review and merge
settings, and report duplicate chat-title prefixes before proposing changes.
```

Prefixes help distinguish chats, such as `SHOP PR #42` and `DOCS PR #42`.
The catalog reports duplicates; it does not enforce unique names or synchronize
settings. Ask to see its location and entries before changing it. Deleting the
catalog leaves each repository's settings intact.
